# Self-hosted typography

The DDU editorial design uses these fonts from their official Fontsource packages (version 5.3.0):

- DM Sans, variable weight, Latin subset — interface and body text.
- Newsreader, variable weight, Roman and italic, Latin subset — editorial headings.
- IBM Plex Mono, regular, Latin subset — identifiers and small technical labels.

Font binaries are served locally; no font CDN requests are made. The original SIL Open Font License notices are included beside each family. System font fallbacks handle characters outside the provided subsets, including Greek compound names.
